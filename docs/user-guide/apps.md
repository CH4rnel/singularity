# Apps and Downloads

Cyberia can be used in a browser or through desktop, mobile, and browser-extension packages. The same network and public addresses work across these surfaces.

## Choose an app

| Experience | Best for | Start here |
| --- | --- | --- |
| Browser | Opening Cyberia immediately without installing an app | <https://cyberia.church/wallet> |
| Desktop | A dedicated Cyberia window on a computer | <https://cyberia.church/download> |
| Mobile | Using the Cyberia site and wallet experience on a phone | <https://cyberia.church/download> |
| Browser extension | Connecting a Cyberia wallet directly to compatible web applications | <https://cyberia.church/download> |

## Install step by step

1. Open the official download page at <https://cyberia.church/download>.
2. Choose your operating system and package type.
3. Download the current package from the link shown there.
4. Complete the operating system's installation flow.
5. Open Cyberia and confirm that the displayed site belongs to `cyberia.church`.
6. Create a new wallet or restore the recovery phrase for the wallet you intend to use.
7. Make a small receive-and-send test before moving the rest of your assets.

## Move between devices

A recovery phrase recreates the accounts derived from that phrase. It does not copy local app preferences, custom networks, or separately imported private keys.

1. Confirm the original recovery phrase backup offline.
2. Install Cyberia on the new device from the official download page.
3. Choose **Restore** and enter the phrase in its original order.
4. Set a new local vault password for the new device.
5. Compare the restored public addresses with the original wallet.
6. Re-add any custom networks and separately imported accounts you still use.

## Browser wallet compatibility

Cyberia is an EVM network, so applications can also connect to wallet-standard providers such as MetaMask or Rabby. Add the network using [Getting started](getting-started.md), then verify chain ID `49406` before signing.

For the built-in multichain wallet, see the full [Cyberia Wallet guide](wallet.md).
